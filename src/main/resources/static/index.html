Query 1: Products with Available Stock

Retrieves all products with stock > 0, SKU, category, unit price, and total valuation in descending order of availability.

SELECT p.id, p.sku, p.name, c.name AS category, p.price, i.quantity, (p.price * i.quantity) AS total_value
FROM products p
JOIN categories c ON p.category_id = c.id
JOIN inventories i ON p.id = i.product_id
WHERE i.quantity > 0
ORDER BY i.quantity DESC, p.name ASC;
